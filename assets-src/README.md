# Source files for generated assets

- `og.html` renders `public/og.png`, the 1200×630 link-preview image. Open it in a browser at
  1200×630 with the site fonts installed (or next to a `fonts/` folder holding the Archivo Narrow,
  Barlow Condensed and JetBrains Mono woff2 files) and screenshot it.
- `../resume-src/resume.html` renders `public/resume.pdf`: print it to a Letter-size PDF.
